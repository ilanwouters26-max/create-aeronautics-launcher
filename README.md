# Create Aeronautics Launcher

Launcher officiel du modpack **Create Aeronautics** (Minecraft 1.21.1 · NeoForge).

## Télécharger

➡️ **[Télécharger la dernière version](../../releases/latest)** — fichier `CreateAeronauticsLauncher-Setup-x.x.x.exe`

Installe-le, lance-le, puis clique sur **Jouer**. Le launcher installe le modpack,
Java et NeoForge automatiquement — rien d'autre à faire.

> Windows peut afficher un avertissement « Windows a protégé votre ordinateur »
> (l'application n'est pas signée numériquement). Clique sur **Informations
> complémentaires** puis **Exécuter quand même**.

## Mises à jour

Le launcher se met à jour **tout seul** : au démarrage, il vérifie s'il existe une
version plus récente ici, la télécharge en arrière-plan et propose de redémarrer.
Le modpack, lui, se met à jour via le bouton **Mettre à jour** du launcher.

## Ce dépôt

Ce dépôt ne contient **que les releases** du launcher (les installeurs `.exe`).
Il est utilisé par le système de mise à jour automatique intégré à l'application.
